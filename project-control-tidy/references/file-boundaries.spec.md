# 控制面文件边界规范

用于裁决 `AGENTS.md`、`README.md`、`justfile` 各自承载什么。

目标：避免把约束、语义、导航、执行入口混写到同一个文件里。

## `AGENTS.md`

作用：承载协作约束和前置条件。

裁决问题：agent 进入仓库后，去哪找什么、能/不能做什么、必须满足什么条件才能正确执行。

应包含：

1. **文件约定**（必写）：声明三元体系——命令入口在 `justfile`，项目背景与模块职责在 `README.md`，行为约束在本文档。这是 agent 首次进入时的导航锚点。
2. **开发环境**（按需）：必需的运行时版本、首次初始化步骤、已知环境坑位、需要预先配置的外部依赖。这些信息既不是可重复执行的命令也不是背景介绍，但缺失时 agent 会直接做错。
3. **编码风格**：项目级的代码规范、语言用法和跨任务成立的工程约束（最小盘点、变更边界、验证义务、协作立场等）。
4. **什么时候停、什么时候问**：agent 必须暂停或请求人工处理的真实场景。
5. **规则生效**：多层 `AGENTS.md` 的继承、覆盖和优先级规则。

对 monorepo，root `AGENTS.md` 还应声明：子目录可能存在该目录专属的 `AGENTS.md`，根部规则在未被子目录覆盖时继续生效。

详细 guideline 参考 [`agents.guideline.md`](agents.guideline.md)。

不应包含：

- 项目背景与模块职责介绍 → `README.md`
- README 式导航说明 → `README.md`
- 命令参数、构建步骤等命令使用细节 → `justfile`
- 项目实现原理说明 → `README.md`
- 只对单次任务有效的临时偏好

## `README.md`

作用：承载最小概述、职责说明和文档索引。

裁决问题：读者进入当前目录后，应先理解什么、继续去哪里读。

应包含：

1. 标题与一句话概述。
2. 职责与边界，说明当前目录负责什么、不负责什么。
3. 相关目录、文档、示例或上下游关系的索引。
4. 只有确有必要时才写的最小使用入口或最小阅读入口。

对 monorepo 的 root `README.md`，还应包含各子项目的简要用途说明，让读者一眼理解仓库全貌。

详细 guideline 参考 [`readme.guideline.md`](readme.guideline.md)。

不应包含：

- 协作规则与优先级 → `AGENTS.md`
- 停止条件或接管条件 → `AGENTS.md`
- 命令参数与执行细节 → `justfile`
- 需要长期维护的详细背景说明
- 只有 agent 才需要遵守的行为约束

## `justfile`

作用：承载统一执行入口。

裁决问题：当前仓库或目录有哪些稳定、可重复调用的命令入口。

应包含：

1. 对不同语言工具链的统一聚合入口。
2. 通过 `mod` 暴露下层稳定入口（对 monorepo 的子项目目录注册为子模块；对 `tool/<lang>/` 工具链目录注册为全局工具链声明，配合 `[no-cd]` 使命令相对于调用方执行）。
3. 每个 recipe 紧邻的文档注释，确保 `just --list` 可直接读懂用途。
4. 必要且最小的参数说明。

详细 guideline 参考 [`justfile.guideline.md`](justfile.guideline.md)。

不应包含：

- 业务背景介绍 → `README.md`
- README 式长说明 → `README.md`
- 与当前入口无关的协作规则 → `AGENTS.md`
- 临时、一次性或尚未确认稳定的任务命令

## 边界裁决流程

处理任何内容前，依次判断：

1. 它是否告诉 agent 去哪找什么、能/不能做什么或必须满足什么前置条件？是则进入 `AGENTS.md`。
2. 它是否帮助人或 agent 理解职责、边界或阅读路径？是则进入 `README.md`。
3. 它是否是稳定、可重复执行的命令入口？是则进入 `justfile`。
4. 若三者都不是，默认不写入控制面文件。

当同一段内容看似可放入多个文件时，按主要用途裁决，不复制多份。必要时只在另一个文件中保留短链接。

## 文件新增规则

只有以下条件同时成立时，才新增控制面文件：

1. 当前路径确实缺少稳定协作所需的最小骨架。
2. 新文件承载的是独立且长期存在的职责。
3. 该职责不能由上层现有控制面自然覆盖。

以下情况默认不新增：

1. 只是为了让目录"看起来完整"。
2. 上层控制面已经充分覆盖当前目录。
3. 当前目录没有独立协作边界或稳定执行入口。
4. 只是临时任务、示例草稿、测试夹具或普通源码目录。

若新增文件会改变协作边界、入口注册或 workspace 结构，必须先请求确认。
